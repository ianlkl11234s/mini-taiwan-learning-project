# 台鐵軌道草稿編輯進度

> 此目錄存放「車站直連」的原始草稿，供在 geojson.io 手繪編輯用。
> 編輯完成後，會整合到正式的軌道檔案中。

## 編輯說明

1. 打開 [geojson.io](https://geojson.io)
2. 選擇要編輯的 `.geojson` 檔案
3. 依照地圖/衛星影像描繪軌道曲線
4. 完成後複製 JSON 貼回檔案
5. 在下方更新狀態
