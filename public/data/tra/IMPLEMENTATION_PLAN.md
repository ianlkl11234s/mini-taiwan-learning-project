## 📝 注意事項

1. **WL-N 是關鍵**：先處理好共用軌道，宜蘭線和基隆線才能並行
2. **手繪是瓶頸**：YL 的手繪區段是最耗時的部分
3. **驗證很重要**：每個步驟完成後都要驗證軌道品質（座標跳躍 < 500m）
4. **漸進式推進**：先完成 A1（樹林↔蘇澳），確認流程正確後再處理其他 O-D
