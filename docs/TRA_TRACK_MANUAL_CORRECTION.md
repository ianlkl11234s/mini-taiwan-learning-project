# TRA 軌道手動修正記錄

> 日期：2026-01-07

## 概述

本文件記錄台鐵軌道資料的手動修正流程。由於官方 SHP 資料在部分區段存在錯誤（長距離跳躍、路線偏離），需要透過手動繪製來修正這些問題區段。

## 修正流程

### 1. 識別問題區段

使用 `scripts/snap_stations_to_tracks.py` 檢測站點與軌道的對齊狀況，找出距離過遠的站點，即為需要修正的區段。

### 2. 建立修正模板

將問題區段加入 `public/data/tra/gaps_to_fill.geojson`，包含：
- 起訖站點標記 (Point)
- 直線連接模板 (LineString)

### 3. 手動繪製修正

在 [geojson.io](https://geojson.io) 開啟 `gaps_to_fill.geojson`，沿著實際軌道路線手動繪製正確的線段。

### 4. 合併修正資料

將手繪完成的線段合併到對應的軌道檔案（如 `YL-0.geojson`、`YL-1.geojson`），並移除原本的錯誤資料。

## 軌道檔案結構

### 上行/下行處理原則

- 每條路線有 `-0`（上行）和 `-1`（下行）兩個檔案
- 手繪修正時，**上行和下行使用相同的軌道資料**
- 修正一方後，需同步更新另一方

## 注意事項

1. **方向一致性**：手繪線段需注意方向，確保與軌道連接順序一致
2. **重複資料清理**：修正後需移除其他軌道檔案中的重複資料
3. **驗證**：修正後執行 station snapping 驗證對齊狀況
