# TRA 軌道手動修正記錄

> 日期：2026-01-08 (更新)

## 概述

本文件記錄台鐵軌道資料的手動修正流程。由於官方 SHP 資料在部分區段存在錯誤（長距離跳躍、路線偏離），需要透過手動繪製來修正這些問題區段。

## 修正流程

### 1. 識別問題區段

使用 `scripts/snap_stations_to_tracks.py` 檢測站點與軌道的對齊狀況，找出距離過遠的站點，即為需要修正的區段。

### 2. 建立修正模板

將問題區段加入 `public/data/tra/gaps_to_fill.geojson`，包含：
- 起訖站點標記 (Point)
- 直線連接模板 (LineString)

### 3. 手動繪製修正

在 [geojson.io](https://geojson.io) 開啟 `gaps_to_fill.geojson`，沿著實際軌道路線手動繪製正確的線段。

### 4. 合併修正資料

將手繪完成的線段合併到對應的軌道檔案（如 `YL-0.geojson`、`YL-1.geojson`），並移除原本的錯誤資料。

## 官方資料常見問題與修正方式

### 問題類型一：手繪資料與官方資料重疊

當手繪 gap 合併到軌道檔案後，可能與官方資料在同一區段重疊，造成視覺上出現兩條軌道。

**修正方式**：在站點座標處切斷官方資料，保留正確的部分

| 路線 | 問題區段 | 修正方式 |
|------|----------|----------|
| NH 南迴線 | 枋野～太麻里 | 官方資料在枋野 (lng≤120.72) 和太麻里 (lng≥121.00) 切斷，中間接 gap-06 |
| TD 臺東線 | 瑞穗～三民 | 官方資料在瑞穗 (lat≥23.4977) 和三民 (lat≤23.4246) 切斷，中間接 gap-04 |
| BH 北迴線 | 和仁～武塔 | 移除整段官方 Seg 2，保留 gap-16 + gap-01 |

### 問題類型二：軌道方向錯誤（逆向）

部分 segment 方向與主線相反，造成軌道折返或視覺上出現兩條線。

**修正方式**：反轉逆向 segment 的座標陣列

```python
# 反轉 segment
coords[i] = coords[i][::-1]
```

| 路線 | 問題 segment | 原方向 | 修正 |
|------|--------------|--------|------|
| WL-N 縱貫線 | Seg 5 (南港→台北) | ←西 | 移除（與 gap-10 重疊）|
| WL-N 縱貫線 | Seg 6, 7 (汐科→南港方向) | ←西 | 反轉為 →東 |

### 問題類型三：軌道迴圈（Turnaround）

Segment 內部有點座標「往回走」，造成軌道形成 U 形迴圈。

**修正方式**：找出經度/緯度最大點，裁切掉往回走的部分

```python
# 找最大經度點，裁切到該點
max_idx = max(range(len(seg)), key=lambda i: seg[i][0])
coords[i] = seg[:max_idx + 1]
```

| 路線 | 問題站點 | 原因 | 修正 |
|------|----------|------|------|
| YL 宜蘭線 | 大溪站 | gap-02 起點有 4 個往回走的點 | 裁切起點 (28→24 pts) |
| WL-N 縱貫線 | 樹林/南樹林 | Seg 1 & Seg 2 結尾往回走 | Seg 1: 2316→2286 pts, Seg 2: 124→104 pts |

### 問題類型四：Segment 間隙

相鄰 segment 的終點和起點不連續，造成軌道有缺口。

**修正方式**：將下一個 segment 的起點設為上一個 segment 的終點

```python
coords[i + 1][0] = coords[i][-1].copy()
```

| 路線 | 連接站點 | 修正 |
|------|----------|------|
| WL-N 縱貫線 | 台北、松山、南港 | 調整 Seg 3→4→5→6 連接點 |
| YL 宜蘭線 | 大溪、大里 | 調整 Seg 1→2→3 連接點 |

### 問題類型五：Segment 順序錯誤

Segment 未按經度順序排列，造成軌道連接混亂。

**修正方式**：按起點經度排序所有 segments

```python
indexed = [(seg, seg[0][0]) for seg in coords]
indexed.sort(key=lambda x: x[1])
coords = [seg for seg, lon in indexed]
```

## 注意事項

1. **方向一致性**：手繪線段需注意方向，確保與軌道連接順序一致
2. **重複資料清理**：修正後需移除其他軌道檔案中的重複資料
3. **驗證**：修正後執行 station snapping 驗證對齊狀況
4. **上行/下行同步**：WL-N-0 和 WL-N-1 使用相同資料，修正時需同步更新兩個檔案
5. **迴圈檢測**：合併 gap 後檢查是否有座標往回走的情況
