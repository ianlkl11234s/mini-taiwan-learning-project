## 每階段標準工作流程

```
1. 決定區段範圍
2. 檢查 all_tracks_backup.geojson 品質
3. 如果 OK → 直接提取
   如果有問題 → 手繪修正
4. 建立 O-D 軌道 (tracks_od/)
5. 更新 od_station_progress.json
6. 發一班測試車驗證
7. 確認無問題後，更新此 memo 狀態
8. Commit
```
